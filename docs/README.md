## 阅读顺序建议

- **只想跑起来**：根 `README.md` 的「快速开始」→ 使用说明 §2；
- **部署到服务器**：使用说明 §2（离线包/pm2）→ §3 配置 → §8 监控；
- **改代码 / 加数据源**：架构设计 §2–§6 → `AGENTS.md` → `.github/skills/add-datasource`；
- **对外提供服务**：架构设计 §3（local/remote）→ §8 安全模型 → 使用说明 §7；
- **做技术决策**：技术选型 → 架构设计 §11 演进路线。

- **单一事实来源**：URL、API 分组、错误码以架构设计 §5–§6 为准；环境变量以 `.env.example` 为准；
  工具参数以 `GET /api/v1/mcp/tools` 为准，不在文档里逐项维护。
- 文档提到代码位置时用相对路径，不写死本机绝对路径。
- 改配置项 / 新增工具 / 调整路由时，同步更新对应文档与 `CHANGELOG.md`。
